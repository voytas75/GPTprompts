# Deepen task (not bigger)

Source: Felix Rieseberg, *How to be more ambitious: A tutorial for humans with models* (13 October 2026).

## Prompt

I want a deeper version of this task, not a bigger one.  
Before rewriting it:  
(1) say what a top professional in this field would do here that I'm not asking for;  
(2) name the rawest material they would start from instead of what has already been digested for me;  
(3) name the specific methods and tools they would use;  
(4) say what, other than you or me, would show the result is right.  

Then rewrite my prompt to ask for exactly that.

## Usage

Paste your original task or prompt after the above text. The model returns a short diagnosis of the four points followed by a rewritten prompt that keeps the original scope while raising the standard of inputs, methods, and verification.
